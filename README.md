# TutorAI

TutorAI is an open-source, web-based AI language tutor. It runs entirely in the browser using the Gemini API.

### Try it out
[Link to live demo will go here]

### Languages Supported
The app currently supports learning and native UI translations for the following languages:
* English
* Spanish
* French
* Italian
* German
* Chinese

### Features
* **Speaking:** Voice-to-voice conversation practice with a live transcript.
* **Writing:** Text editor with grammar correction and feedback.
* **Reading:** Level-adjusted stories with a tap-to-translate feature and quizzes.
* **Notebook:** Flashcards and notes saved locally to the browser.
* **Local Storage:** All user data, stats, and API keys are stored locally on the user's device. No backend required.

### Setup Locally
1. Navigate to the frontend directory: `cd frontend`
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
